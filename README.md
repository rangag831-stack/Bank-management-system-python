
# Python Banking Management System

## Project Description
The Python Banking Management System is a GUI-based application developed using Python and Tkinter. It allows users to create bank accounts, log in securely, deposit money, withdraw money, check balances, and view transaction history.

The application uses CSV files to store account details and transaction records so that data is available even after closing the application.

## Features
- Create a new bank account.
- Secure user login with password hashing.
- Show/Hide password option.
- Deposit and withdraw money.
- Check account balance.
- Store account details in CSV files.
- Automatically load saved account details.
- View the last 5 transactions.
- Account summary report.
- Delete account with confirmation.
- Support multiple users.
- Calculate 5% annual interest.
- User-friendly GUI using Tkinter and ttk widgets.

## Technologies Used
- Python
- Tkinter
- CSV
- Object-Oriented Programming (OOP)
- File Handling
- JSON
- Hashlib

## Project Files
- `Python_Banking_Management_System.py` – Main application.
- `accounts.csv` – Stores account details and balances.
- `transactions.csv` – Stores deposit and withdrawal records.

*The CSV files are automatically created when the application saves data.*

## How to Run
1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the following command:

```bash
python Python_Banking_Management_System.py
```
